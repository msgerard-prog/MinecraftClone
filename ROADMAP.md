# Roadmap

Claude rewrites **Status** and **Next** every session and ticks steps as they land.
Milestone details live here; design detail lives in `docs/`.

## Status (2026-10-06)
M1 done: fly camera with vanilla rotation conventions and mouse sensitivity,
`--pos/--look`, 10 placeholder block textures (generated by
`tools/textures/gen_placeholders.py`), block texture atlas with mipmaps and
`missingno`, cube mesher with vanilla face shading and grass tint, a test scene of
textured cubes. 19 test cases. Interactive controls (WASD/mouse) compile and are
unit-tested but have only been verified by scripted screenshots, not by hand.
Next session starts M2.

## Next
1. M2.1 — `world::Block` registry + block-state table (properties, dense `uint16`
   state ids, `minecraft:oak_log[axis=y]` string form) with tests. ADR if the design
   has real alternatives.
2. M2.2 — `Section` (palette + packed indices) and `Chunk` (24 sections), get/set
   with tests (incl. palette growth and negative coordinates).
3. M2.3 — Mesher: per-section face culling against neighbours (inc. across section and
   chunk borders), replacing `buildTestScene`.
4. M2.4 — Worker-thread meshing + main-thread upload; flat 8×8-chunk world; 60 fps check.
