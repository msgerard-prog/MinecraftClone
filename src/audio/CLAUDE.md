# audio — local rules
Sound playback (M22.4, ADR 0008): `SoundEngine` over Windows XAudio2 2.9 (system API,
no dependency). Depends on `core` only: it plays loaded WAV buffers by handle; `main`
maps vanilla sound events (`world/Sounds`) to handles.

- No allocation when playing (hard rule 1): a fixed voice pool, buffers loaded at start.
- All XAudio2/COM code stays in `SoundEngine.cpp`; without a device everything is a
  silent no-op (tests and screenshot runs never open audio).
- Sounds in the repo are our own (ADR 0004), generated by `tools/sounds/gen_sounds.py`.
